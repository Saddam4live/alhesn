# MikroTik Hotspot Error Messages (Arabic Translation)
internal error: خطأ داخلي في النظام
user <$(username)> not found: لم يتم العثور على اسم المستخدم أو رقم البطاقة غير صحيح
user already logged in: هذا الحساب مسجل دخول مسبقاً من جهاز آخر
invalid password: كلمة المرور غير صحيحة
invalid username: رقم البطاقة غير صحيح
no more sessions: تم تجاوز الحد الأقصى للجلسات المسموح بها لهذا الحساب
uptime limit reached: انتهى الوقت المسموح به لهذه البطاقة
traffic limit reached: انتهى رصيد البيانات (التحميل) المسموح به لهذه البطاقة
transfer limit reached: انتهى رصيد نقل البيانات لهذه البطاقة
user <$(username)> has reached uptime limit: انتهى وقت بطاقتك
user <$(username)> has reached traffic limit: انتهى رصيد بطاقتك
credit limit reached: انتهى رصيد الحساب
session limit reached: تم استنفاد عدد الجلسات المتاحة
mac address is not valid: عنوان الماك غير صالح
license limit reached: تم الوصول إلى الحد الأقصى لمستخدمي الشبكة
simultaneous session limit reached: لا يمكن تسجيل الدخول من أكثر من جهاز في نفس الوقت
